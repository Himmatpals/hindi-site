PDF to Image कैसे करें?

  1. PDF upload करें — हर page thumbnail में दिखाई देगा.
  2. जिन pages की image चाहिए उन्हें selected रखें.
  3. JPG या PNG चुनें.
  4. 2x resolution सामान्यतः अच्छा balance है.
  5. Images बनाएं दबाएं. एक page image के रूप में, multiple pages ZIP में मिलेंगे.

JPG या PNG?

  • JPG: WhatsApp, email और smaller file size के लिए.
  • PNG: text, charts, screenshots और sharper edges के लिए.
  • 1x–1.5x: lightweight output.
  • 2x: recommended general quality.
  • 3x–4x: high detail, लेकिन memory और file size काफी बढ़ सकते हैं.
