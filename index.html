A LITTLE HELP / 04

शुरू करने से पहले

PDF से सिर्फ एक page कैसे निकालें?

Split PDF खोलें, file चुनें और उस page का number लिखें। चुना हुआ page एक नई PDF में मिलेगा।

क्या PDF हमेशा 500 KB से छोटी हो सकती है?

हर file अलग होती है। Compress PDF में target size आज़माएं और download से पहले result देखें। Pages और image quality के कारण हर target मिलना संभव नहीं है।

मेरी PDF कहाँ process होती है?

Split PDF, Merge PDF, Compress PDF और PDF to Image में PDF processing आपके browser में होती है। बाकी tools की जानकारी उनके pages पर देखें। अधिक जानकारी के लिए Privacy Policy पढ़ें।

क्या phone पर tools इस्तेमाल कर सकते हैं?

हाँ। Tool खोलें और अपने phone से file चुनें। बड़ी PDFs को process करने में आपके device की memory और file size के अनुसार अधिक समय लग सकता है।
