PDF Alag Karna Kaise Kare?

  1. ऊपर PDF File चुनें button से अपनी PDF select करें।
  2. Pages निकालें, Ranges में अलग करें या हर page अलग mode चुनें।
  3. जरूरी pages लिखें — जैसे 1-3, 5, 8-10.
  4. PDF अलग करें button दबाएं।
  5. Result को PDF या ZIP के रूप में download करें।

PDF से Pages निकालने के 3 तरीके

  • एक या कुछ pages: PDF से सिर्फ page 2 या pages 2-5 चाहिए हों।
  • Multiple sections: PDF को chapter-wise या document-wise अलग PDFs में बांटना हो।
  • हर page अलग: पूरे PDF के हर page की separate PDF चाहिए हो।
  • Preview: Split करने से पहले selected pages check कर सकते हैं।

PDF अलग करने से जुड़े सवाल

PDF upload करें, Pages निकालें, Ranges में अलग करें या हर page अलग mode चुनें। जरूरी pages select करके PDF अलग करें button दबाएं।
हाँ। Pages निकालें mode में सिर्फ page number लिखें, जैसे 3. इससे सिर्फ page 3 की नई PDF बनेगी।
Pages निकालें mode में 1-3, 5, 8-10 जैसा लिख सकते हैं। इससे pages 1,2,3,5,8,9,10 एक नई PDF में आएंगे।
Ranges में अलग करें mode चुनें और 1-3 | 4-6 | 7-10 जैसे ranges लिखें। हर range से अलग PDF बनेगी।
हर page अलग mode चुनें। Tool PDF के हर page की separate PDF बनाएगा और सभी files एक ZIP में download की जा सकती हैं।
जब एक से ज्यादा PDF files बनती हैं — जैसे Ranges में अलग करें या हर page अलग mode में — तो सभी PDFs ZIP file में download होती हैं।
