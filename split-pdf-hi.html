PDF split कैसे करें?

  1. ऊपर PDF file upload करें।
  2. Split mode चुनें।
  3. Page range लिखें, जैसे 1-3, 5, 8-10।
  4. PDF Split करें button दबाएं।
  5. Output PDF या ZIP download करें।

Range कैसे लिखें?

  • 1-3 = page 1 से 3 तक
  • 1,3,5 = केवल page 1, 3 और 5
  • 2- = page 2 से last page तक
  • 1-2, 6-8 = multiple ranges
  • गलत या page limit से बाहर numbers automatically reject होंगे।
