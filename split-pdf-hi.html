PDF अलग कैसे करें?

  1. ऊपर PDF file upload करें।
  2. Mode चुनें: Extract, Split by ranges, या Every page.
  3. Page range लिखें जैसे 1-3, 5, 8-10.
  4. PDF अलग करें button दबाएं।
  5. Single PDF या ZIP download करें।

कौन सा mode कब use करें?

  • Extract pages: PDF से कुछ pages निकालकर एक नई PDF बनानी हो।
  • Split by ranges: PDF को sections में तोड़ना हो, जैसे chapter-wise.
  • Every page: हर page को अलग PDF file बनाना हो।
  • Preview: Pages check करने के लिए split करने से पहले preview देखें।

FAQ

हाँ, Extract pages mode में सिर्फ page number लिखें, जैसे 3. इससे सिर्फ page 3 की PDF बनेगी।
आप 1-3, 5, 8-10 जैसा लिख सकते हैं। इसका मतलब pages 1,2,3,5,8,9,10 होंगे।
| अलग-अलग output PDF बनाने के लिए है। जैसे 1-3 | 4-6 से दो अलग PDFs बनेंगी।
जब output एक से ज्यादा PDFs होंगी, जैसे Split by ranges या Every page mode में, तो ZIP download होगी।
यह page browser-side libraries का उपयोग करता है। फिर भी sensitive documents के लिए हमेशा सावधानी रखें।
