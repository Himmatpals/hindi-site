PDF अलग करने का आसान तरीका

  1. PDF upload करें — pages thumbnails में दिखाई देंगे.
  2. जिन pages की जरूरत है उन्हें tap करके select करें.
  3. Selected pages की एक PDF, अलग PDFs की ZIP या Visual Split mode चुनें.
  4. जरूरत हो तो selected pages rotate करें.
  5. Create PDF दबाकर result download करें.

Visual Split क्या है?

Visual Split mode में किसी page card पर ✂ button दबाएं. इसका मतलब उस page के बाद नई PDF शुरू होगी. Example: Page 3 और Page 8 पर split mark लगाने से Pages 1–3, 4–8 और 9–last की अलग PDFs बनेंगी.
