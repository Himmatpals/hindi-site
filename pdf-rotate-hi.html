PDF rotate कैसे करें?

  1. ऊपर PDF file upload करें।
  2. Rotation direction चुनें: right, left या 180°।
  3. All pages या selected pages choose करें।
  4. PDF Rotate करें button दबाएं।
  5. Ready PDF download करें।

कब कौन सा option use करें?

  • Right 90°: Page left side पड़ा है और clockwise घुमाना है।
  • Left 90°: Page right side पड़ा है और anticlockwise घुमाना है।
  • 180°: Page उल्टा scan हुआ है।
  • Selected pages: जब सिर्फ कुछ pages wrong direction में हों।

FAQ

हाँ, All pages mode में पूरी PDF के सभी pages rotate होंगे।
हाँ, Selected pages mode चुनकर 1-3, 5, 8-10 जैसा range लिखें।
यह tool PDF pages की rotation property बदलता है, इसलिए normally quality loss नहीं होता।
Password-protected या damaged PDFs rotate नहीं हो सकतीं। पहले PDF unlock करनी होगी।
यह page browser-based PDF library का उपयोग करता है। फिर भी sensitive documents के लिए हमेशा सावधानी रखें।
