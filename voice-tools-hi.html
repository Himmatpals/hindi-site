Text-to-Speech कैसे use करें?

  1. Text box में Hindi, Punjabi या English text लिखें।
  2. Language select करें या Auto Detect रखें।
  3. Voice choose करें और speed/pitch/volume adjust करें।
  4. Speak दबाएं। Pause, Resume और Stop controls use करें।
  5. Text copy या download कर सकते हैं।

Speech-to-Text कैसे use करें?

  1. Speech → Text tab खोलें।
  2. Recognition language choose करें।
  3. Start Listening दबाएं और microphone permission allow करें।
  4. Final transcript edit, copy या download करें।
  5. Transcript को Text-to-Speech में भेजकर सुन भी सकते हैं।
