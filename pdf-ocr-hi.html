PDF OCR कैसे करें?

  1. Scanned PDF upload करें और page analysis complete होने दें.

  3. Language, quality और preprocessing चुनें.

  5. Text-layer verification pass होने के बाद searchable PDF download करें.

इस rebuild में क्या अलग है?

पुराने implementation में हर selected page JPEG में rebuild होती थी और invisible text Helvetica में draw किया जाता था. यह version normal mode में original PDF pages preserve करता है और Hindi/Punjabi के लिए Unicode fonts embed करता है.

Accuracy tips

  • Clean 250–300 DPI scan पर Balanced या Sharp mode अच्छा रहता है.
  • Faded documents में Grayscale + contrast try करें.
  • Forms/receipts में Sparse Text layout useful हो सकता है.
  • Bilingual page पर matching combined language model चुनें.
