Privacy Policy

HindiTools.com आपकी privacy को महत्व देता है। यह policy बताती है कि हमारी website पर files, analytics, cookies, ads और contact information कैसे handle की जाती है।

1. हमारी website का उपयोग

HindiTools.com PDF, image, voice और language tools provide करता है। कई tools browser-based libraries का उपयोग करके आपके device/browser में process करने की कोशिश करते हैं।

कुछ advanced features, जैसे OCR, AI-supported tools, voice tools, Word/PDF conversion या third-party browser APIs, external services, APIs या server-side processing की जरूरत रख सकते हैं।

Important: बहुत sensitive, confidential, legal, medical, financial या private documents process करने से पहले tool की instructions ध्यान से पढ़ें।

2. Files और document processing

जहाँ संभव हो, हम tools को browser में run करने के लिए design करते हैं, ताकि files आपके device पर ही process हो सकें। फिर भी हम यह guarantee नहीं देते कि website का हर tool हमेशा 100% local/browser-only processing ही करेगा।

Future या advanced tools में file, text या document को processing के लिए third-party service/API या server पर भेजा जा सकता है। ऐसे tools में जहाँ practical हो, हम notice देने की कोशिश करेंगे।

3. Personal information

हम सामान्य tool usage के लिए आपका नाम, address या phone number नहीं मांगते। अगर आप contact form या email के माध्यम से हमें message भेजते हैं, तो आपका नाम, email address और message केवल reply देने और support purpose के लिए use किया जा सकता है।

4. Analytics और usage data

हम website improvement के लिए analytics tools, जैसे Google Analytics या similar services, का उपयोग कर सकते हैं। इससे हमें समझने में मदद मिलती है कि कौन से pages/tools useful हैं, errors कहाँ आते हैं और website performance कैसी है।

Analytics data में browser type, device type, approximate location, visited pages, time on site और referral source जैसी सामान्य जानकारी शामिल हो सकती है।

5. Cookies

Cookies छोटी files होती हैं जो आपके browser में save हो सकती हैं। HindiTools.com cookies का उपयोग settings, analytics, website performance और advertising purposes के लिए कर सकता है।

आप अपने browser settings में cookies block या delete कर सकते हैं। Cookies disable करने पर कुछ features ठीक से काम न करें।

6. Advertising और Google AdSense

HindiTools.com Google AdSense या अन्य third-party advertising networks का उपयोग कर सकता है। ये services cookies और similar technologies का उपयोग करके ads दिखा सकती हैं और ad performance measure कर सकती हैं।

Third-party vendors, including Google, cookies का उपयोग आपकी previous visits के आधार पर ads serve करने के लिए कर सकते हैं। आप अपने Google ad settings में personalized ads manage कर सकते हैं।

हमारी website PDF, image, voice और अन्य features के लिए third-party JavaScript libraries, browser APIs या external links का उपयोग कर सकती है। External websites की अपनी privacy policies होती हैं, और उनके content या practices के लिए HindiTools.com जिम्मेदार नहीं है।
