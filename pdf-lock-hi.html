PDF lock कैसे करें?

  1. ऊपर PDF file upload करें।
  2. Open password और confirm password लिखें।
  3. Password strength check करें।
  4. Printing, copying और editing permissions choose करें।

Strong password tips

  • कम से कम 10–12 characters रखें।
  • Capital letter, small letter, number और symbol use करें।
  • नाम, birthday या phone number password में न रखें।
  • Password भूलने पर PDF unlock करना मुश्किल या impossible हो सकता है।
