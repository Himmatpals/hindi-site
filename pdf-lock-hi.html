PDF पर password कैसे लगाएं?

  1. PDF upload करें और source security check होने दें.
  2. Password to open mode में open password set करें.
  3. Separate owner password रखें या auto-generated key save करें.
  4. Print, edit और copy permissions चुनें.
  5. Encrypt & Verify PDF दबाएं और verified result download करें.

Open vs Owner password

  • Open/User password: PDF खोलने के लिए.
  • Owner password: full access / security settings control के लिए.
  • Same user + owner password रखने की बजाय separate owner password बेहतर है.
  • Permissions-only mode में PDF बिना open prompt खुलेगी; owner key restrictions manage करती है.

Security notes

  • AES-256 इस tool का default है.
  • Password strength meter guidance है; weak password encryption को practical attacks के सामने कमजोर बना सकता है.
  • Permissions reader-enforced हैं; confidentiality के लिए open password जरूरी है.
  • Large PDFs mobile पर ज्यादा memory ले सकती हैं क्योंकि encryption browser WebAssembly में होती है.
