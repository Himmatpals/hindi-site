Image to PDF कैसे करें?

  1. ऊपर JPG, PNG या WebP images upload करें।
  2. Images का order check करें। जरूरत हो तो ऊपर/नीचे move करें।
  3. Page size, margin, orientation और fit mode चुनें।
  4. PDF बनाएं button दबाएं।
  5. Ready PDF download करें।

कौन सी settings best हैं?

  • Documents/forms: A4, Portrait, Contain, Margin 12–24
  • Photos: A4 या Auto, Cover या Contain
  • Full page scan: Margin 0 और Contain
  • File size कम चाहिए: Quality 70–85%
  • High clarity चाहिए: Quality 90–100%
